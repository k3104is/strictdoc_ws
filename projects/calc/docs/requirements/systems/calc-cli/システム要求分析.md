# calc CLI システム要求分析

## 1. システムコンテキスト

対象は、計算を実行して結果または理由を返し、その実行ログを運用担当者へ提示する calc CLIである。

| 項目 | 内容 |
|---|---|
| 外部アクター | 利用者、運用担当者 |
| 外部システム | コマンドシェル、実行環境のファイルシステム |
| 入力インタフェース | コマンドライン引数、ログ提示要求 |
| 出力インタフェース | 標準出力、標準エラー出力、終了コード、計算ログ |
| 境界 | 引数受付、検証、演算、結果提示、ログ記録・提示 |
| 運用状態 | 入力待ち、検証、演算、ログ記録、正常終了、異常終了、ログ提示 |
| 前提・制約 | 1回の計算起動で1演算を実行し、有限な数値結果を扱う |

計算ログはlog/YYYY-MM-DD.logへ追記し、対象日のファイルが存在しない場合は自動生成する。正常時は「HH:MM:SS | <左辺> <演算子記号> <右辺> | <結果>」、異常時は「HH:MM:SS | ERROR | <異常内容>」を1回の計算につき1行で記録する。logディレクトリが存在しない場合は入出力異常として標準出力へ通知する。保存期間とアクセス制御は本機能の実装範囲外とし、必要になった時点で要求を追加する。

## 2. ユースケース抽出

| ID | ユースケース | 目的 | アクター | 関連要求 |
|---|---|---|---|---|
| UC-01 | 四則演算を実行する | 結果または実行できない理由を把握する | 利用者 | CALC-STK-004 |
| UC-02 | 計算ログを確認する | 実行状況および失敗原因を調査する | 運用担当者 | CALC-STK-005 |
| UC-03 | 計算ログを記録する | 後から調査できるよう計算の実行状況および失敗原因を残す | なし（UC-01から包含） | CALC-STK-005 |

UC-01とUC-02はアクターの目的と完了条件が異なるため分割する。ログ記録はアクターが単独で開始する目的ではないが、UC-01から常に呼び出され、独自の正常・代替・例外フローを持つため、UC-03を包含ユースケースとして分離する。UC-03が生成した計算ログをUC-02が後から利用する。

## 4. ユースケースシナリオ分析

### UC-01 四則演算を実行する

- 事前条件：利用者がシステムを起動できる。
- トリガー：利用者が演算子と2つのオペランドを指定して起動する。
- 事後条件：ログ書き込み異常の場合を除き、計算結果または実行できない理由が提示される。ログ書き込み異常の場合は、その異常が提示されて非0で終了する。

#### メインフロー

| ステップID | 実行者 | 内容 |
|---|---|---|
| UC-01-MF-01 | 利用者、コマンドシェル | 演算子と2つのオペランドを指定してcalc CLIを起動する。 |
| UC-01-MF-02 | calc CLI | コマンドライン引数を検証する。 |
| UC-01-MF-03 | calc CLI | 指定された演算子に対応する四則演算を実行する。 |
| UC-01-MF-04 | calc CLI | 正常な計算内容と結果を渡してUC-03を実行する。 |
| UC-01-MF-05 | calc CLI、コマンドシェル | 数値結果を利用者へ提示し、終了コード0で終了する。 |

#### 代替フロー

代替フローはない。

### UC-03 計算ログを記録する

- 事前条件：UC-01が正常な計算結果、入力異常、または計算異常を確定している。
- トリガー：UC-01が計算内容と結果、または異常内容を渡してUC-03を実行する。
- 事後条件：計算の実行状況または失敗原因が実行日の計算ログへ記録される。書き込み異常の場合は、その異常が標準出力へ提示され、UC-01へ失敗が返される。

#### メインフロー

| ステップID | 実行者 | 内容 |

| UC-03-MF-01 | UC-01、calc CLI | UC-01から計算内容と結果、または異常内容を受け取る。 |
| UC-03-MF-02 | calc CLI | 実行環境のローカル日付および時刻を取得する。 |
| UC-03-MF-03 | calc CLI | 時刻、計算内容、および計算結果から正常ログ行を生成する。 |
| UC-03-MF-04 | calc CLI、ファイルシステム | 生成したログ行を実行日の計算ログへ追記する。 |
| UC-03-MF-05 | calc CLI | UC-01へ記録成功を返す。 |

|---|---|---|---|
| 入力が妥当で有限な結果 | 実行 | 数値結果、終了コード0 | 時刻、計算内容、計算結果 |

各ユースケースのフロー、分岐、およびアクターとの関係はアクティビティ図で表現できるため、補足図は使用しない。

ログの保持期間とアクセス制御は今回の実装範囲外とし、必要になった時点で追加要求として分析する。

## 6. システム要求の分析

7要求は入出力またはログ内容を観測でき、各COMMENTのシステム試験で検証可能である。UC-01が包含するUC-03がログを生成し、UC-02が同じログを利用する依存関係がある。ログ書き込み失敗時は計算結果を出力せず非0で終了する。読み込み失敗時も非0で終了する。保持期間とアクセス制御は今回の実装範囲外である。

## 8. レビューおよび合意
